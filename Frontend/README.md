# MERN Workout App - Frontend

React frontend voor de MERN Workout app met Vite.

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:3000 in je browser.

## Structuur

```
Frontend/
  src/
    components/
      WorkoutForm.jsx      # Form voor nieuw workout
      WorkoutList.jsx      # List van alle workouts
      WorkoutItem.jsx      # Individueel workout item
    App.jsx                # Main app component
    main.jsx               # Entry point
```

## Features

- ✅ GET alle workouts
- ✅ POST nieuw workout
- ✅ PATCH update workout
- ✅ DELETE verwijder workout
